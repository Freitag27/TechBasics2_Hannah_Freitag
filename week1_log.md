### Log Week 1

This week we started Tech Basics two. We started learing about using Arduino, different types of boards and made a simple circuit that made an LED light up. We also started learning about using C++ and how to make the LED blink in different speeds. 

## Main Learnings: 

- Do not directly connect + and -
- in C++ you need to compile the code before putting it on the chip
- you can fry the board so be careful with it.
- many things can go wrong not only with code but also with the physical tech we use.
- in C++ you need to use ; after every line

## New Words: 
IDe: Integrated development Environment, a software like Arduino. It combines many functions, such as code editing, compiling, interpreting... 
Chip: black rechtangle thingy on the board, this is where the computing takes place.
Jumper wires: cables that help you connect everything. they have ends that look a little bit like syringes..
pins: where you put the connections
